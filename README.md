## Overview

Network Devices adds routers, switches and access points to Termix. See their ports, clients and neighbors, get an alert when one goes down, and turn a port off or restart a device from the same place.

Read the [docs](https://docs.termix.site/plugins/network-devices) to set it up and use it.

<br />

## Features

- Any SNMP device (v1, v2c and v3), MikroTik RouterOS, OPNsense and OpenWrt
- Ports with link state, speed, traffic rates, errors, VLAN and PoE
- Clients from DHCP, ARP, Wi-Fi and switch MAC tables
- Neighbors from LLDP and MikroTik discovery
- Alerts when a device or a watched port goes down
- Turn a port off or on, power cycle PoE and restart a device
- Find SNMP devices in an address range
- Keys are stored encrypted and never shown again
- A dashboard card and Termix actions for rules, the CLI and the assistant

## Support

Bugs and ideas for Network Devices go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Network-Devices/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Network-Devices/issues/new?template=feature_request.yml). Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
